- **云端**：公司 Linux 主机（Ubuntu 26.04，Docker，Tailscale）。Mosquitto 只听本机、每设备账号 + ACL；`tailscale funnel` 发布 8443（MQTT/TLS）和 443（HTTPS）。Let's Encrypt 证书，固件带 ISRG Root X1。公网 DNS 约 10 min 生效。Mac 本机 DNS 走代理解析到内网 IP，需 hosts 记录。

## 三、踩坑清单（都在实板上真实发生）

1. `tonumber(nil)` 报错；`fskv.get` 缺键无返回值 → 写 `tonumber(x or "")`。
2. 内置库 `log`/`gpio` 等是只读表，不能 monkeypatch，用代理表。
3. GPIO26 是 I2C1 外围供电：G-sensor 必须拉高，任何人不能拉低。
4. `exaudio` 请求过 "new" 框架后不可逆；V2030_1 只有旧 `audio` 库。
5. USB 回复按 ≤480 字节分段；macOS 上串口在途时 `tcflush` 会卡死，只能重开句柄。
6. 换电脑插 USB 要按 `reset`；真断电后要长按 `PWRKEY`；SIM 必须真断电插。
7. Luatools 要勾「忽略脚本依赖性」；新文件必须手动加进列表；三次"烧好了"实际没烧进去（config.lua 未覆盖/新文件未加入），每次都靠日志版本行核对。
8. 电池路径压降大：4G 发射/马达/摄像头都可能触发欠压重启（原因码 `0 0 5`），无 USB 时尤甚。
9. 桥/App/固件三处 device_id 必须一致。
10. Python 走系统代理访问 127.0.0.1 会失败（Mac 有 SkyVPN），curl 不受影响。
