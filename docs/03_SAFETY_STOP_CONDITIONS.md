# 安全停止条件与测试纪律

## 立即停止动物试戴（方案第 8 节）

- 电池鼓包、漏液、异常发热、保护反复动作。
- 外壳开裂、锐边、可脱落小件、pogo 异常导通。
- 25°C 环境下可触表面超过 42°C、电芯超过 45°C、设备频繁复位或无法远程停止执行器。
- breakaway 不释放或设备位置影响呼吸、进食和正常活动。
- 宠物出现持续抓挠、僵住、逃避、呼吸异常或其他明显应激。

## 台架测试纪律

- 锂电样机、充电测试、首次硬件上电：必须有人在场。
- 无人值守（如 9/25～9/27 假期 soak）只允许：已过安全检查的 1 台样机、限流台式电源（不接锂电）、阻燃箱、温度/烟雾监测、远程断电。
- 震动/LED/蜂鸣最坏组合只做台架测试，不在动物身上做。
- 震动在动物上只用最低档，且先在固定夹具验证；不做惩罚式训练。
- 充电时摘下项圈。
- 电池任何批次无规格资料、鼓包或保护异常，不得用于动物试戴。

## 固件不可绕过的安全上限（方案 3.4）

| 项 | 上限 |
|---|---|
| 单次震动脉冲 | ≤500 ms |
| 单命令次数 | ≤3 次 |
| 两次命令间隔 | ≥30 s |
| 低电量 / 充电中 / 温度异常 | 拒绝执行并返回原因 |

TP-04 必须验证这些上限在**固件本地**生效，即使后端下发超限参数。

## 凭据与标识

- Wi-Fi/MQTT 凭据、证书、密钥只放 `firmware/wearable-evt0/config.lua` 或环境变量，已在 `.gitignore`。
- IMEI/ICCID 只写入 `records/device_ledger.csv` 的本地副本，不写入公开日志或 daily report。
