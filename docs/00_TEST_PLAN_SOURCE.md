# 宠物项圈MPV方案
# PetPal 真正可佩戴项圈 EVT0：30 天设计、采购与实现计划
### 0.1 月底必须交付什么
在 30 天内完成一套“定位 + 找回”的真正可佩戴项圈工程样机闭环：
1. **2 台可佩戴 EVT0 样机**：2 台用于受控试戴。
2. **定位闭环**：项圈通过 4G 上传 GNSS/LBS、活动和电量；App 显示当前位置、位置新鲜度和轨迹。
3. **找回闭环**：App 下发寻宠模式、震动、LED、蜂鸣/声音提示；项圈返回命令 ACK。
4. **低功耗闭环**：静止、日常移动、寻宠、低电量、充电五种状态可切换，完成真实功耗记录。
5. **安全闭环**：无电弧模块；震动有强度/次数/冷却硬限制；电池有保护和温度监控；采用 breakaway 安全扣。
6. **工程资料**：冻结版 BOM、原理图/载板资料、结构 3D 文件、固件源码、接口协议、测试记录和 EVT0 复盘报告。

## 1. 产品与技术边界
### 1.1 P0 功能
1. GNSS 户外定位；无 GNSS 时允许 LBS 回退，但必须在 UI 区分精度。
2. 最后位置、位置时间、定位来源、估计精度和最近轨迹。
3. 日常模式、寻宠模式、低电量模式。
4. 远程震动、LED、蜂鸣/提示音，带命令状态与过期机制。
5. 电量、电压、充电状态、4G 信号、固件版本、最后在线时间。
6. 静止/移动检测，用于唤醒和调整上报频率。
7. 低电量、离线和电子围栏事件。
8. 离线缓存、恢复补传、看门狗、远程日志和 FOTA。
### 1.2 P1：只预留，不阻塞月底交付
- BLE 近距离寻找和 RSSI 距离趋势。
- 活动量、步数和日统计。
- 录制主人提示音或更完整的音频功能。
- 家庭基站 BLE 网关。
### 1.3 必须删除或隔离
- 电弧模块、电弧 GPIO、电弧 HTTP API、短信触发电弧和 App 电弧入口必须从动物版构建中全部移除。
- Wi-Fi SSID、密码、MQTT 凭据不得硬编码在源码或提交到 Git。
- 所有会改变状态的命令不得使用无鉴权 GET 请求。
- 摄像头、MJPEG、LittleFS 音频上传等代码不进入 wearable 固件，避免无关功耗和攻击面。

## 2. 推荐样机架构
### 2.1 硬件路线
**主路线：Air8201G-LM 成品 PCBA + 小型功能载板 + 300 mAh 锂电 + 独立天线 + 3D 打印外壳。**
选择理由：
- Air8201G-LM 集成 4G、GNSS、LBS、G-sensor、BLE、音频和充电管理，主板尺寸约 16 × 33 × 4 mm。
- BLE 可以为后续“最后几十米”寻找保留能力；首月可只完成前台扫描验证。
- 以 LuatOS 实现 MQTT、GNSS、低功耗、缓存和 FOTA，不再保留 ESP32+A7670E 双主控电源域。
- 使用成品 PCBA 避开首月 RF 主板 Layout 和回流焊风险，把精力放在天线、结构和系统闭环。
**开发工具：Air8201G-BLMQ + 官方调试板/FPC。** BLMQ 带 BTB 扩展接口，适合桌面开发和功耗探测；可佩戴样机使用 LM，避免调试连接器增加厚度。
**回退路线：Air8201G 基础版。** 如果 9 月 4 日前确认 LM 的 BLE/音频导致功耗、天线或结构不可控，则去掉 BLE/音频，保留 4G+GNSS+G-sensor+充电；附近寻找改为 4G 指令触发震动/LED。
### 2.2 硬件框图
```Plain Text
300 mAh 1S LiPo + 保护板 + NTC
          │
          ├── Air8201G-LM PCBA
          │     ├── 4G Cat.1 ── LTE FPC 天线
          │     ├── GNSS ─────── GNSS FPC/陶瓷天线
          │     ├── BLE ──────── BLE FPC 天线（LM）
          │     ├── G-sensor
          │     ├── 充电管理
          │     └── LuatOS / FOTA / 缓存
          │
          └── 2 层功能载板
                ├── 1027 ERM 震动马达 + MOSFET + 续流保护
                ├── 低电流 RGB/单色 LED
                ├── 可选蜂鸣器
                ├── 4-pin 磁吸 pogo 充电触点
                └── 调试/产测测试点
```
### 2.3 功能载板要求
- 2 层、0.8 mm FR-4、沉金；只承载低速控制和电源，不承载 LTE/GNSS 射频匹配。
- 预留 VBAT、GND、充电输入、PWM/GPIO、I²C、UART/调试、PWRKEY、RESET 测试点。
- 震动马达使用逻辑电平 MOSFET，马达两端增加合适的反向/瞬态保护；默认上电必须关闭。
- LED 静态电流应尽量控制在 2 mA 以内；状态灯不得常亮。
- 充电入口有反接、过流和湿水短路保护；样机充电时要求摘下项圈。
- 确认 Air8201G-LM 充电管理是否包含所需 NTC 行为；如不满足，载板补充温度检测和软件禁止充电逻辑。
- 电池必须带独立保护板，不能把软件保护当作唯一保护。
### 2.4 电池与电源目标
首选电池：**302535 或接近尺寸的 300 mAh、1S、持续放电 ≥3C、带保护板和 NTC 的软包电池**。
供应商必须提供或配合测量：
- 常温内阻；0°C/低电量条件下的脉冲压降。
- 最大持续/脉冲放电电流。
- 过充、过放、过流保护参数。
- 充电温度范围、循环容量保持率。
- UN38.3；如果后续销售，再补齐面向目标市场的电池合规资料。
功耗验证必须覆盖：
|状态|测试内容|
|---|---|
|关机/运输|实际漏电和存放损耗|
|PSM+|5 分钟平均、1 小时积分|
|低功耗在线|MQTT 长连接、下行唤醒延迟|
|定位|冷启动、热启动、超时失败三种能耗|
|上报|强信号、弱信号、重连、QoS1 重传|
|寻宠|连续 GNSS + 15/30 秒上报|
|执行器|马达、LED、蜂鸣启动峰值|
|充电|0～100%、温升、异常断开/重接|
官方同系列测试出现约 700～800 mA 发射峰值，因此电源与仪表必须覆盖至少 1 A 瞬态；PPK2 可用于平均/睡眠电流，峰值同时用示波器+采样电阻或 ≥3 A 量程能量分析仪复核。
### 2.5 结构设计
目标外形：约 **42 × 30 × 12 mm**，圆角、背面微弧、电子舱与织带连接点独立承力。
设计要求：
1. PCBA 与电池叠层，GNSS 天线位于外侧顶部，尽量远离电池和猫颈；LTE 天线位于另一端。
2. 不在天线正上方使用金属螺钉、磁铁或大面积铜箔；磁吸充电组件靠近底部边缘。
3. Rev A 使用 PA12/SLS 或高强度树脂外壳 + TPU/硅胶垫 + 螺钉/卡扣，方便返修。
4. PCB 三防漆，壳体使用密封圈；EVT0 只声明“防泼水工程验证”，不宣称正式 IP67。
5. 不做完全灌封，避免首月无法返修、无法换天线；DVT 再评估局部灌封和二次包胶。
6. 使用 breakaway 安全扣；释放力由目标猫体重、织带供应商资料和重复拉脱测试共同确定，不拍脑袋固定一个数值。
7. 结构上防止设备翻转到猫喉正下方；至少准备“居中固定”和“侧向固定”两种佩戴方案比较。
8. 任何外露表面无锐角、无可被咬下的小件；pogo 触点做限流和防误短路。
### 2.6 重量预算
|项目|目标重量|
|---|---|
|Air8201G-LM PCBA + 三天线|≤6.0 g（以实测为准）|
|300 mAh 电池|≤6.5 g|
|载板、马达、pogo、线束|≤3.0 g|
|外壳、密封圈、紧固件|≤8.0 g|
|主体目标|≤23.5 g|
|织带 + breakaway|≤6.5 g|
|整机目标|≤30.0 g|
若 Day 12 实测预测超过 32 g：按顺序砍掉蜂鸣器、音频器件、装饰灯和多余紧固件；不得通过取消 breakaway、电池保护或密封来减重。

## 3. 软件与接口实现
### 3.1 系统链路
```Plain Text
项圈（LuatOS）
    │ MQTT/TLS，设备独立凭据
    ▼
公网 MQTT Broker
    │ 后端主动建立出站连接
    ▼
现有 Linux 后端 ── SQLite WAL ── REST/SSE ── iOS App
```
原则：项圈不暴露 HTTP Server，不依赖局域网 IP，不直接加入 Tailscale；App 也不直接访问项圈。现有 Linux 后端可继续位于内网/Tailscale 内，只需主动连接公网 Broker。
### 3.2 MQTT Topic
```Plain Text
petpal/v1/{device_id}/telemetry  # QoS 1，周期遥测
petpal/v1/{device_id}/event      # QoS 1，低电量/围栏/重启等事件
petpal/v1/{device_id}/state      # QoS 1 + retained，设备影子/在线状态
petpal/v1/{device_id}/cmd        # QoS 1，后端到设备
petpal/v1/{device_id}/ack        # QoS 1，设备命令回执
```
Broker 配置：
- 每台设备独立 username/password 或证书；禁止共享全局密钥。
- ACL 只允许设备发布自己的 telemetry/event/state/ack，只允许订阅自己的 cmd。
- TLS 1.2+；服务端和设备都校验时间与证书。
- Last Will 将 retained state 设置为 `online=false`。
- 后端对 QoS1 重复消息按 `device_id + seq` 去重。
### 3.3 最小遥测结构
```JSON
{
  "v": 1,
  "device_id": "collar-evt-001",
  "seq": 1234,
  "ts": 1788200000,
  "mode": "routine",
  "position": {
    "source": "gnss",
    "lat": 31.2304,
    "lng": 121.4737,
    "accuracy_m": 8.0,
    "fix_age_s": 4
  },
  "motion": {"state": "moving", "steps": 312},
  "battery": {"pct": 76, "mv": 3890, "charging": false},
  "radio": {"rsrp_dbm": -91, "rssi_dbm": -68},
  "fw": "evt0.1.0"
}
```
规则：无可靠定位时不得上报 `0,0`；允许 `position=null`，同时保留最后有效位置及时间。
### 3.4 命令与回执
```JSON
{
  "id": "cmd-uuid",
  "issued_at": 1788200000,
  "expires_at": 1788200030,
  "type": "VIBRATE",
  "args": {"duration_ms": 200, "count": 2}
}
```
设备必须：
1. 检查目标设备、时间和过期时间。
2. 对 `command_id` 去重；重传不能造成重复震动。
3. 先回 `accepted`，执行完成再回 `executed`；失败回 `rejected/error`。
4. 在固件本地设置不可绕过的安全上限：单脉冲 ≤500 ms、单命令 ≤3 次、两次命令至少间隔 30 秒。
5. 电量过低、充电或温度异常时可拒绝执行，并返回明确原因。
### 3.5 固件状态机
|模式|进入条件|GNSS|网络/上报|下行响应|
|---|---|---|---|---|
|`stationary`|持续静止|关闭|60 分钟心跳|低功耗在线；若功耗不达标则周期唤醒|
|`routine`|检测到移动|5～15 分钟定位|5 分钟遥测|目标 P95 ≤10 秒|
|`lost`|App 启用或围栏触发|连续|15～30 秒|保持在线，2 小时后提示续期|
|`low_power`|电量 <15%|30～60 分钟一次|60 分钟心跳|允许延迟；禁用高耗执行器|
|`charging`|检测到充电|诊断时按需|5 分钟|允许 FOTA/日志；禁止震动|
状态和最近 1,000 条遥测写入掉电保存区；写入频率要做合并，避免 Flash 过度磨损。
### 3.6 后端改造
新增一个独立 MQTT Bridge，避免把设备重连和 Broker 逻辑散落在现有 AI 监控线程中：
- 订阅所有已登记设备的 telemetry/event/state/ack。
- 校验 schema、设备 ID、时间范围、经纬度范围和消息大小。
- SQLite WAL 表：`devices`、`telemetry`、`commands`、`device_events`。
- 提供命令 API：`POST /api/collar/{id}/commands`。
- 保留并落实现有设备/历史接口：`GET /api/collar/devices`、`GET /api/collar/{id}/telemetry`。
- 通过 SSE 向 App 推送设备状态、位置和命令 ACK。
- 记录 MQTT 重连、重复消息、解析错误、设备离线和命令超时指标。
### 3.7 iOS 改造
- 真项圈页面改用后端设备 ID，不再要求用户输入 ESP32 IP。
- GPS 页面读取后端历史轨迹，并明确展示 GNSS/LBS、位置时间和精度圈。
- 震动/寻宠按钮展示 `发送中 → 已接收 → 已执行/失败/超时`，避免用户反复点击。
- 电量低于 15%、设备离线、位置陈旧时给出醒目提示。
- BLE 近距离寻找只做前台页面；首月不承诺 iOS 后台持续扫描。
- 保留开发板直连功能在 `DEBUG` 构建，Release/EVT 构建不显示电弧和开发板摄像头入口。
