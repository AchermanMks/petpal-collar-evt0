# EVT0 验收标准

> 新版方案删除了旧版 0.2/0.3，但逐日计划与 Gate 仍引用这些数字。以下沿用旧版并按“2 台样机”修订，**待项目负责人确认**。

## 一个月内明确不承诺（沿用）

- 不承诺量产、正式认证或正式 IP67 报告。
- 不做项圈摄像头和实时视频。
- 不做双向语音、UWB、室内精确坐标、3D/视觉融合。
- 不做模具，不采购 100 台以上物料，不锁定大批量供应商。
- 不允许无人看护的整夜动物试戴。

## 成功判定

| 指标 | EVT0 通过线 | 测量方法 | 规程 |
|---|---|---|---|
| 可佩戴数量 | 2 台，功能一致、唯一设备 ID、出生证齐全 | 设备台账 | TP-01 |
| 含项圈带重量 | 目标 ≤30 g；硬上限 35 g | 0.1 g 电子秤，整机 + 织带 + breakaway | TP-08 |
| 日常模式续航 | ≥5 天（实测或 ≥24 h 等效连续测试外推） | PPK2/Joulescope 积分，`tools/power_analyzer.py` | TP-03 |
| 寻宠模式续航 | ≥4 h（GNSS 连续、15～30 s 上报） | 同上，实际放电 | TP-03 |
| 在线命令回执 | routine/lost 模式 P95 ≤10 s | `tools/ack_checker.py` | TP-04 |
| 户外位置误差 | 开阔环境中位数 ≤10 m，同时记录 P95 | 与手机参考轨迹对比，`tools/gnss_accuracy.py` | TP-09 |
| 断网恢复 | 恢复覆盖后 ≤2 min 重连，离线数据不丢失 | 20 次断网/恢复 | TP-04 / TP-09 |
| 稳定性 | 连续 72 h 无死机；自动恢复单独计数 | 长跑日志 | TP-07 |
| 遥测完整性 | 每台 ≥500 条，无不可解释缺口，重复可去重 | `tools/telemetry_validator.py` | TP-04 |
| 命令执行 | 每台 ≥100 条，≥99% 最终 ACK，0 次重复执行 | `tools/ack_checker.py` | TP-04 |
| FOTA | 正常/断网/断电各 ≥1 次，不变砖 | 人工 + 日志 | TP-07 |
| 安全 | 无裸露锐边/高压/过热；电池、充电、breakaway 全部检查 | 安全放行表 | TP-08 |
| 热安全 | 25°C 环境下可触表面 ≤42°C、电芯 ≤45°C | 热电偶/红外，弱网连续上报 + 充电 | TP-06 |

## 数据可信度规则

1. 每个数字都要能追溯到 `records/raw/` 下的原始文件、设备 ID、固件版本和日期。
2. 模组/裸板标称值只能作为对比参考，不能填进通过线。
3. 单次测试不算通过；矩阵 7.1～7.3 的样本数是最低要求。
