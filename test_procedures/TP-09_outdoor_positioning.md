# TP-09 户外定位与弱网

**目的**：在真实户外路线中量化 fix 成功率、误差分布、LBS 回退和断网补传行为。
**对应方案**：6 (9/21)、02 户外位置误差 / 断网恢复。
**样本**：≥2 台样机同行，手机 GPS 记录参考轨迹（GPX）。

## 路线

| 路线 | 环境 | 时长 |
|---|---|---|
| R1 | 开阔（操场/广场） | ≥30 min |
| R2 | 居民区 / 树荫 | ≥30 min |
| R3 | 地下 / 无覆盖（地库、地铁站） | ≥15 min，含进出 |

每条路线：样机固定于步行者腰部/手持（模拟猫颈高度约 0.3 m 更佳），routine 与 lost 各跑一遍。

## 步骤

1. 手机开启 GPX 记录（1 s 间隔）；样机时间已对时。
2. 行走路线；R3 进入前记录最后位置，出来后记录重连时间。
3. 导出后端遥测为 JSONL，手机 GPX；运行 `python3 tools/gnss_accuracy.py telemetry.jsonl reference.gpx`。
4. 检查 App：位置来源（GNSS/LBS）、位置年龄、精度圈是否与数据一致；位置陈旧提示是否出现。
5. 电子围栏：设定围栏，走出后确认事件到达（只验证服务器逻辑）。

## 指标

- fix 成功率（每次定位尝试）。
- 误差中位数 / P95（GNSS 点对参考轨迹最近点）。
- LBS 回退次数与 LBS 误差。
- R3 出来后重连时间、补传条数与顺序。

## 通过标准

- R1 中位误差 ≤10 m（同时记录 P95）。
- 恢复覆盖后 ≤2 min 重连，离线数据完整。
- 无 `0,0` 上报；UI 正确区分 GNSS / LBS。
