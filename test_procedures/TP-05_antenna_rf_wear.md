# TP-05 天线、射频与佩戴模拟

**目的**：在裸板、整机、织带、贴身/湿毛四种条件下量化 LTE 与 GNSS 性能差异，选出天线候选与佩戴方向。
**对应方案**：2.5、4.3 天线候选、6 (9/16)、7.3 湿毛/贴身 RF。
**样本**：Rev A 样机 ≥3（覆盖两种佩戴方向、两种天线组合）。

## 条件矩阵

| 条件 | 说明 |
|---|---|
| C1 裸板 | PCBA + 官方天线，桌面 |
| C2 整机 | 装入外壳 + 电池 + 载板 |
| C3 织带 | 整机装在织带上，悬挂 |
| C4 贴身 | 整机贴在含水介质模型（盐水袋 / 仿生猫颈）上；再加湿毛巾覆盖模拟湿毛 |

天线组合：A（官方/推荐）、B（可穿戴 FPC 候选 B）；佩戴方向：居中、侧向。

## 测量项（每条件 ≥5 次，同一地点同一时段）

- LTE：RSRP、RSSI、注册/重连时长、5 条遥测发布成功率。
- GNSS：冷/热 TTFF、卫星数、CN0 均值、与参考点误差（固定点连续 5 min 取中位数）。
- BLE（LM）：手机在 1 / 5 / 10 m 的 RSSI。
- 每条件拍照记录天线走向。

## 佩戴结构检查（C3/C4）

- 翻转倾向（悬挂后是否转到底部）。
- 压颈点、摄食/饮水姿态干涉（用仿生模型模拟低头）。
- 居中 vs 侧向：GNSS 天线朝天的比例。

## 记录

`records/antenna_ab.csv`：`date, device_id, condition, antenna_set, mount, rsrp_dbm, rssi_dbm, reg_time_s, pub_ok_rate, ttff_cold_s, ttff_hot_s, sats, cn0_avg, pos_err_m, ble_rssi_1m, ble_rssi_5m, notes`

## 通过标准

- C4 相对 C1 无“系统性失联”（发布成功率 ≥95%，RSRP 劣化 ≤10 dB 记录但不阻断）。
- C4 GNSS 热启动 TTFF ≤60 s，误差中位数 ≤15 m（台架），否则天线位置/方向进入 Rev B 修改。
- 输出天线选择与佩戴方向结论，写入 G2 记录。
