# 外壳 Rev A / Rev B（方案 2.5）

目标外形约 42 × 30 × 12 mm，圆角，背面微弧，电子舱与织带连接点独立承力。

| 项 | Rev A（订单 C，6 套） | Rev B（订单 D，10 套） |
|---|---|---|
| 材料 | PA12/SLS 或高强度树脂 + TPU/硅胶垫 | 修复重量、天线、密封、佩戴问题后 |
| 固定方式 | 3 套居中 + 3 套侧向 | 按 TP-05 结论选一种 |
| 天线 | GNSS 外侧顶部，LTE 另一端，天线上方无金属/磁铁 | 同左，按 TP-05 A/B 数据调整 |
| 密封 | 密封圈 + PCB 三防漆；只声明防泼水 | 同左 |
| 灌封 | 不做完全灌封 | DVT 再评估 |
| 安全 | breakaway、无锐角、无可咬下小件、pogo 限流 | 同左 |
